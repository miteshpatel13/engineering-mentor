# Skill Creator

Create Skills using `context/skills/Skill Development Standard.md`.

Before finalizing:
1. Define purpose and scope.
2. Define triggers and required context.
3. Define workflow and constraints.
4. Define validation.
5. Define edge/failure cases.
6. Create realistic test scenarios.
7. Ensure no project-specific assumptions leak into a global Skill.
