# Debugging SOP

Use evidence rather than assumptions.

1. Collect logs, traces, metrics, errors, and reproduction details.
2. Build a timeline.
3. Narrow the failure boundary.
4. Form a hypothesis.
5. Verify the hypothesis.
6. Trace dependencies.
7. Identify root cause.
8. Fix and validate.
9. Add regression protection.
10. Capture reusable lessons if the issue reveals a global engineering weakness.
