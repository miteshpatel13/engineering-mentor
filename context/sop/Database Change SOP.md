# Database Change SOP

1. Define the data requirement.
2. Inspect current schema and access patterns.
3. Assess data volume and production impact.
4. Design constraints and indexes.
5. Create a reproducible migration.
6. Consider backward compatibility during rollout.
7. Test migration and rollback strategy.
8. Validate query performance.
9. Verify application compatibility.
10. Plan for large-table or long-running migration risk.
