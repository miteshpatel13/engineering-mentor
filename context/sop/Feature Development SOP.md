# Feature Development SOP

1. Understand the requirement.
2. Identify business rules and acceptance criteria.
3. Inspect existing architecture and related code.
4. Identify impacted APIs, database objects, integrations, and tests.
5. Design the smallest robust change.
6. Implement incrementally.
7. Add or update tests.
8. Run relevant validation.
9. Review security, performance, compatibility, and observability.
10. Review the final diff for unrelated changes.
11. Document important behavior or decisions.
