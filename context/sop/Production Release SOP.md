# Production Release SOP

1. Confirm scope and acceptance criteria.
2. Confirm tests and validation passed.
3. Review migrations and backward compatibility.
4. Review configuration and secrets.
5. Review observability and alerting.
6. Prepare rollback or mitigation strategy.
7. Verify deployment sequence.
8. Deploy using the established process.
9. Monitor health and key metrics.
10. Confirm expected behavior.
11. Record important incidents or lessons.
