# Bug Fixing SOP

1. Reproduce the problem.
2. Establish expected versus actual behavior.
3. Trace the execution path.
4. Identify the root cause.
5. Check whether concurrency, data, caching, or external dependencies contribute.
6. Implement the smallest correct fix.
7. Add regression coverage.
8. Test adjacent behavior.
9. Review production impact.
10. Document the root cause when it is operationally important.
