# Skill Development Standard

A production Skill should define:

- Name
- Purpose
- Scope
- Trigger/use cases
- Inputs
- Required context
- Workflow
- Rules
- Constraints
- Validation
- Edge cases
- Failure handling
- Expected output
- Examples where useful

A Skill must be actionable, testable, reusable, and specific enough to produce consistent behavior.

Do not encode project-specific business knowledge in a global Skill unless the Skill is explicitly scoped to that project.
