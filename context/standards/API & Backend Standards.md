# API & Backend Standards

- Validate all untrusted input at boundaries.
- Use consistent API conventions.
- Use appropriate HTTP semantics where REST is used.
- Return predictable response and error structures.
- Enforce authentication and authorization server-side.
- Avoid N+1 database access.
- Use pagination for large collections.
- Use timeouts for external dependencies.
- Consider idempotency for retryable operations.
- Design for duplicate requests and concurrency.
- Document contracts, validation, errors, and important business rules.
