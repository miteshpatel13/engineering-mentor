# Code Review Standard

Review in priority order:

1. Correctness
2. Security
3. Data integrity
4. Compatibility
5. Performance
6. Reliability
7. Maintainability
8. Testing
9. Readability

For every finding, identify:
- Severity
- Location
- Problem
- Impact
- Recommended fix

Separate required fixes from optional improvements. Do not demand unrelated refactoring.
