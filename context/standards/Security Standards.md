# Security Standards

Treat all external input as untrusted.

Always consider:
- Authentication
- Authorization
- Input validation
- Injection
- Secret handling
- Sensitive-data exposure
- Secure logging
- Dependency risk
- File-upload safety
- Rate limiting and abuse prevention

Never trust client-provided identity, role, ownership, permissions, pricing, or privileged flags.

Never hardcode credentials or expose secrets in logs or responses.
