# Engineering Principles

1. Correctness before optimization.
2. Security by design.
3. Prefer simple solutions.
4. Make behavior explicit.
5. Preserve existing contracts unless change is intentional.
6. Minimize unrelated changes.
7. Validate at system boundaries.
8. Design for failure, not only success.
9. Measure performance before optimizing.
10. Treat data integrity as a first-class requirement.
11. Prefer automated verification.
12. Make operational behavior observable.
13. Avoid premature abstraction.
14. Document important decisions and trade-offs.
15. Treat AI-generated output as untrusted until validated.
